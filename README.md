# SIH Building Intelligence

An offline building-intelligence system for converting 2D building
blueprints into a verified digital representation with indoor
navigation and route planning.

## Project Status

🚧 Under Development

## Planned Features

- 2D blueprint upload and preprocessing
- Detection of walls, rooms, doors and stairs
- Confidence-aware verification
- Semantic building graph
- Indoor route calculation using Dijkstra / A*
- Estimated route time
- Automatic alternate-route calculation
- 3D building visualization
- Offline operation and local data storage

## Proposed Technology

- Computer Vision / OpenCV
- Graph algorithms
- Three.js
- Local storage / database
- Electron for offline desktop packaging

## Problem Statement

Smart India Hackathon 2026

## Project Goal

Build the system from the ground up as a practical,
offline-capable software application for understanding
and navigating building floor plans.
